# Project Tracker

Full-stack project tracker with an asynchronous Claude-powered risk review.

- `backend/` — FastAPI + async SQLAlchemy (SQLite) + Anthropic SDK, managed with `uv`
- `frontend/` — Vite + React + strict TypeScript, TanStack Query, API client generated by [hey-api](https://heyapi.dev) from the backend's OpenAPI spec, UI built with [shadcn/ui](https://ui.shadcn.com) (Radix + Tailwind CSS v4)

## Setup

```sh
cp .env.example .env          # then set ANTHROPIC_API_KEY
cd backend && uv sync
cd ../frontend && npm install
```

## Run

```sh
# terminal 1
cd backend && uv run uvicorn src.main:app --reload    # http://localhost:8000/docs

# terminal 2
cd frontend && npm run dev                            # http://localhost:5173 (proxies /api → :8000)
```

## Regenerating the API client

The frontend's service layer (`frontend/src/api/generated/`) is generated, never hand-edited:

```sh
cd frontend && npm run gen:api
```

This exports `openapi.json` from the backend app (no running server needed) and runs `openapi-ts`,
producing typed SDK functions, TanStack Query options and Zod schemas. Run it after any backend API change.

## UI components

`frontend/src/components/ui/` holds [shadcn/ui](https://ui.shadcn.com) components (Radix base, Nova preset, see
`components.json`). They are copied into the repo and can be edited. Add more with:

```sh
cd frontend && npx shadcn@latest add <component>
```

Imports use the `@/` alias for `frontend/src/`.

## Checks

```sh
# backend
cd backend
uv run ruff check --fix . && uv run ruff format .
uv run mypy
uv run pytest

# frontend
cd frontend
npm run lint && npm run format:check && npm run typecheck
npm test
npm run build
```
